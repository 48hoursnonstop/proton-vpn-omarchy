# 0.9.6-rc3 — Interaction refinement

This local frontend candidate builds on RC2's native panel. Returning from
Account or About retains the settings section, disclosure, scroll and invoking
control. Switching location tabs retains the query, filter and selected location.
Both Escape and the location Back button restore the preceding search.
Presentation memory lasts only for the workspace lifetime and clears when an
authentication/onboarding gate opens or the agent state object changes.

Space paints the native pressed state while held and activates once on release.
Moving focus cancels it; auto-repeat events do not activate controls. Pointer
presses on rows now differ from hover, and dragging out cancels the click.
Enter retains immediate activation. Shared buttons intercept activation before
the native toolkit's handlers, so both layers cannot execute the same action.

Search shows a localized Searching… indicator throughout debounce and pending
responses, without prematurely showing an empty result. Enter submits immediately,
including an exact server lookup. Clearing restores typing focus and cancels
pending timers; opening a country cancels the obsolete search timers as well.
The indicator reserves one line so its appearance does not move the results.

## Native styling and compatibility

Press fills, focus rings, fonts and surfaces still use `qs.Commons.Style`,
`qs.Commons.Color` and `qs.Ui`. The toolkit's existing color transitions remain;
no custom movement is added to repeated tab, typing or connection actions.
The expanded Advanced network arrow now rotates the existing right-chevron asset
instead of referencing a missing down-chevron file.

`AgentState.qml` differs from RC2 only in its client version. Backend installer,
uninstaller, release pins and hashes remain unchanged, with backend `v0.9.6-rc1`.
This candidate introduces no credential reads, writes, migration or serialization.
UI fixtures use synthetic state; they do not exercise a real login or tunnel.

## Design review

Mode: full within the changed interaction paths and their shared controls.
Framework: Qt Quick/QML and Quickshell, using Omarchy's existing native toolkit.
Applied skills: make-interfaces-feel-better and better-ui from the requested
Jakub Krehel repositories, with Omarchy integration guidance. RC2's broader
layout and accessibility review remains documented in its release notes.

## Verification

Passed locally:

```bash
scripts/check-ui-runtime
scripts/check-traffic-runtime
scripts/check-installer-runtime
scripts/capture-showcase
PROTON_SHOWCASE_ONLY=settings PROTON_SHOWCASE_SCENARIO=advanced PROTON_SHOWCASE_WIDTH=320 PROTON_SHOWCASE_LOCALE=es-MX scripts/capture-showcase /tmp/proton-rc3-advanced
bash -n scripts/capture-showcase scripts/check-ui-runtime
git diff --check
```

The new interaction fixture drives Qt keyboard and mouse events through the
production workspace. It checks Back section/scroll/focus restoration, retained
query/filter, both location Back paths, pending versus empty search, immediate
Enter request counts, clear cancellation, account-gate memory clearing, held
Space without early activation, native pressed color, focus-loss cancellation,
pointer drag-out cancellation, busy rejection and single Enter activation.
The workspace regression verifies offscreen focus reveal after opening a section
in the same event. Existing locale, search, pagination, profile destination,
traffic, installer and closed native Wayland-host checks pass.

Nineteen sanitized route-entry renders were refreshed. Visual inspection focused
on Countries and expanded Advanced network at 320px in Spanish. All captures
use the offscreen platform; visible test hosts are FloatingWindow instances.

Not verified: physical keyboard auto-repeat timing (guarded in code), screen-reader
announcements, frame-time profiling with a full production server catalog,
10% speed motion inspection (no browser animation panel in this native QML host),
and live account/tunnel behavior. These checks remain outside this local UI pass.

Verdict: **Approve for local RC evaluation within the inspected scope**, with
the unverified checks above. This is a local candidate, not a published release.
