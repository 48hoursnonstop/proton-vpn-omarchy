# Social publication assets

The five 1600×838 PNG files in this directory form the recommended Reddit
gallery. `reddit-cover.png` is the lead image; the remaining four present the
profiles, split-tunneling, location and live-status workflows with three
related production screens apiece.

The editable HTML compositions and shared background are retained under
`source/`. They reference the same sanitized 2× production captures used by
the project README. No local account, address, profile or configuration is
used in these assets.

Render the cover and gallery pages in a 1600×838 Chromium viewport at a device
scale factor of 1. Gallery variants are selected with `gallery.html?slide=`
followed by `profiles`, `split`, `locations` or `traffic`.
